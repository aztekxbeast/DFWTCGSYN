1. What We Collect

The PokeHunt Bot collects the following data when you use it in a Discord server:

Data TypeWhat It IsWhy We Collect It
User IDYour Discord user identifierTo track your activity and role access
MessagesMessages in designated channels (not content, just that you sent one)To count chat activity for role maintenance
Role MentionsWhen you mention @location or @OOS rolesTo track store ping contributions
Media PostsWhen you post images in #pulls or #success channelsTo verify active participation
TimestampsWhen actions occurTo enforce time-based activity windows

2. How We Store Data

  • All data is stored in a SQLite database on the server hosting the Bot.
  • Data is stored locally and is NOT sent to any third-party services.
  • The database is maintained by the server administrators who run the Bot.

3. How We Use Data

  • To automatically grant or revoke the "Pokemon Hunter" role based on activity thresholds.
  • To provide ping counts and leaderboards when requested via bot commands.
  • To sync with MEE6 roles if configured by the server admin.

4. Data Retention

  • Activity data is retained for a rolling 14-day window for recent activity checks.
  • All-time ping totals are retained indefinitely for leaderboard purposes.
  • Server admins can clear data using admin commands.

5. Data Sharing

We do NOT share, sell, or transmit your data to any third parties. All data remains on the server where the Bot is hosted.

6. Your Rights

  • Server admins can view, clear, or reset your data using bot commands.
  • You can request data deletion by contacting the server admin.
  • Removing the Bot from your server stops all data collection.

7. Children's Privacy

The Bot is not directed at children under 13. We do not knowingly collect data from children under 13.

8. Changes to This Policy

This Privacy Policy may be updated at any time. Changes will be posted in the Bot's GitHub repository.

9. Contact

For privacy concerns, open an issue at https://github.com/aztekxbeast/RepoHUB/issues
