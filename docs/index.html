About

PokeHunt is a free, open-source Discord bot that tracks user activity (role mentions, media posts, chat messages) to automatically manage Discord role access for Pokemon TCG hunting communities.

Features

  • Ping tracking for in-store stock and OOS alerts
  • Media sharing verification in #pulls and #success channels
  • Chat activity monitoring
  • Automatic role granting/revoking based on activity thresholds
  • MEE6 Silver+ role sync
  • Admin commands for whitelist, settings, and manual overrides
